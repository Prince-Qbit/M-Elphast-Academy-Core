# 🎓 Elphast Academy

> **Structured learning. Practical development. Real-world experience.**

A structured academy focused on practical development, mentorship, and real-world experience. Elphast Academy is my training ground as a student developer to build real projects, sharpen my skills, and expand my coding horizon.

Every project here is small enough to understand end to end, but real enough to teach the habits of professional developers: clean structure, readable code, testing, documentation, and version control.

## 🧭 Learning Path

1. Read the project README to understand the goal.
2. Run the project and study the output.
3. Read the code, starting at `src/index.js`, and follow the imports.
4. Run the tests and try breaking them on purpose.
5. Extend the project with your own features, then commit your work.

## 🤝 Contributing

Contributions from learners are welcome!

1. Fork this repository.
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes and commit them with a clear message: `git commit -m "Add: short description"`
4. Push the branch: `git push origin feature/your-feature-name`
5. Open a Pull Request describing what you changed and why.

Please keep code readable, commented where it helps learners, and tested where possible.
